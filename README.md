# CodeAlpha Machine Learning Internship Projects

This repository contains my completed projects for the **CodeAlpha Machine Learning Internship (Month 1)**, covering supervised classification and predictive modeling techniques.

---

## 📌 Projects Overview

### 1. Task 1: Credit Scoring Model
* **Objective:** Predict an individual's creditworthiness using historical financial data.
* **Approach:** Preprocessed dataset features (income, debts, payment history) and applied classification algorithms (Logistic Regression, Decision Trees, Random Forest).
* **Evaluation:** Assessed model performance using Precision, Recall, F1-Score, and ROC-AUC metrics.

### 2. Task 4: Disease Prediction from Medical Data
* **Objective:** Predict the likelihood of disease occurrences based on structured clinical patient data.
* **Approach:** Evaluated patient indicators (symptoms, age, laboratory metrics) using algorithms such as Support Vector Machines (SVM), Random Forest, and XGBoost.
* **Key Focus:** Performed feature importance analysis to optimize classification accuracy on medical datasets.
